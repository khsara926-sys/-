مشروع نظام عمليات الصيانة المنزلية
تواجه شركات الصيانة المنزلية صعوبات في إدارة طلبات العملاء بفعالية، مما يؤثر على مستوى رضا العملاء وكفاءة العمليات. يهدف هذا المشروع إلى تطوير نظام آلي متكامل لإدارة عمليات الصيانة المنزلية، بدءًا من تسجيل الطلبات وصولًا إلى إنجاز الصيانة وتقييمها، وذلك بهدف تحسين الخدمة المقدمة للعملاء وزيادة كفاءة العمليات الداخلية للشركة.
تم استخدام لغات البرمجة LARAVEL و لغة FLUTTER مع التطبيقات POSTMAN و EXAMPP# -
